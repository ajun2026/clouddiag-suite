# A3 · 端口硬编码导致部署不一致

**类别**：部署 / 代码质量
**状态**：✅ 已改为环境变量可配置

---

## 现象

不同服务器部署同一项目时，端口需求不同（有的用 8002，有的用 8082），
但代码中端口是**硬编码**的，导致：

```
· 每换一个环境就要手工改代码（且容易改漏）
· 改过代码的版本与仓库版本不一致 → 后续升级覆盖后端口又变回去
· 多服务同机部署时容易端口冲突
```

---

## 根因

`main.py` 底部直接写死：

```python
uvicorn.run(app, host="127.0.0.1", port=8082)
```

同类问题还包括各处的 `127.0.0.1:xxxx` 硬编码调用。

---

## 处置过程

改为环境变量可配置（保留原默认值以兼容既有部署）：

```python
_port = int(os.getenv("PORT") or os.getenv("APP_PORT") or "8082")
_host = os.getenv("HOST") or "127.0.0.1"
uvicorn.run(app, host=_host, port=_port)
```

用法：

```bash
PORT=8002 python3 main.py       # 换端口无需改代码
```

同时**对外地址全部收敛到环境变量**（`PUBLIC_URL` / `SERVER_HOST` / `SERVER_PORT`），
代码中不再出现具体部署地址。

---

## 预防措施

1. **任何环境相关的值（端口、地址、路径）都应可配置**，不写死在代码里
2. 配置项要有**默认值**，保证不配置也能在常规环境跑起来
3. 部署文档明确列出**可配置项清单**（见 [03-环境变量说明](../03-环境变量说明.md)）
