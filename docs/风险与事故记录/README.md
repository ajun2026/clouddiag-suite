## 通用预防清单

部署/升级本项目时，建议逐项确认：

- [ ] 系统依赖齐全（`7z` / `unrar` / `lzop` / Python 包）
- [ ] `.env` 已按部署形态配置（特别是 `COOKIE_SECURE`）
- [ ] `PUBLIC_URL` 与实际访问地址一致
- [ ] 端口规划无冲突（server / log-analyzer）
- [ ] 桥接器协议与部署形态匹配（HTTP→`ws://`，HTTPS→`wss://`）
- [ ] 升级时按文件比对，不整体覆盖（避免旧文件覆盖现网修复）
- [ ] `.env` 等含密钥的文件**不进入版本库**
- [ ] 上传压缩包支持 `.rar/.zip/.7z`（`.rar` 需 `unrar`，不能只靠 7z）
- [ ] 部署后跑 `deploy/doctor.sh` 自检
- [ ] 升级前备份（含运行时数据）
