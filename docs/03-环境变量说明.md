# 环境变量说明

两个服务各自维护 `.env`（互不影响）。模板见各目录下的 `.env.example`。

---

## clouddiag-server

| 变量 | 默认值 | 必填 | 说明 |
|---|---|---|---|
| `SERVER_HOST` | `0.0.0.0` | 否 | 监听地址 |
| `SERVER_PORT` | `8000` | 否 | 监听端口 |
| `PUBLIC_URL` | 空 | **是** | 对外访问地址。用于生成桥接器一键连接命令与下载链接。**HTTP 部署填 `http://IP:端口`，HTTPS 填 `https://域名`** |
| `COOKIE_SECURE` | `true` | **是** | 会话 Cookie 是否仅 HTTPS 传输。**HTTP 环境必须设 `false`**，否则登录后立即掉线 |
| `ALLOWED_HOSTS` | 空 | 否 | 允许的 Host 列表（逗号分隔），留空不限制 |
| `AGENT_BRAIN` | `hermes` | 否 | AI 大脑：`hermes`（需配 HERMES_*）或 `deepseek`（直连，需配 OPENAI_*） |
| `OPENAI_BASE_URL` | `https://api.deepseek.com/v1` | 条件 | `AGENT_BRAIN=deepseek` 时必填 |
| `OPENAI_API_KEY` | 空 | 条件 | 同上 |
| `OPENAI_MODEL` | `deepseek-chat` | 条件 | 同上 |
| `HERMES_BASE_URL` | `http://127.0.0.1:8642/v1` | 条件 | `AGENT_BRAIN=hermes` 时必填 |
| `HERMES_API_KEY` | 空 | 条件 | 同上 |
| `HERMES_MODEL` | `hermes-agent` | 条件 | 同上 |
| `BRIDGE_HTTP_SECRET` | 空 | **是** | 桥接器上传日志到 IDG 时的校验密钥（生产环境用随机值） |
| `ADMIN_USERNAME` | `admin` | 否 | 管理员用户名（首次启动写入数据库） |
| `ADMIN_PASSWORD` | `admin` | **是** | 管理员密码（务必修改） |
| `ADMIN_SECRET` | 随机 | 否 | 会话签名密钥；多实例部署时须显式固定，否则各实例会话不通用 |
| `LOG_ANALYZER_UPSTREAM` | `http://127.0.0.1:8002` | **是** | 日志分析服务地址（与 log-analyzer 的 `PORT` 对应） |
| `LOG_ANALYZER_DIR` | `/opt/log-analyzer` | **是** | 日志分析项目目录（用于读取分析结果、写入上传文件） |
| `ENABLE_DESKTOP_TOOLS` | `0` | 否 | 是否启用桌面类工具（截图/鼠标/键盘等）：`1` 启用 `0` 关闭 |

## log-analyzer

| 变量 | 默认值 | 必填 | 说明 |
|---|---|---|---|
| `PORT` / `APP_PORT` | `8082` | 否 | HTTP 监听端口（改端口无需改代码） |
| `HOST` | `127.0.0.1` | 否 | 监听地址（通常只本机访问，由反向代理转发） |
| `DEEPSEEK_BASE_URL` | — | **是** | AI 接口地址 |
| `DEEPSEEK_API_KEY` | — | **是** | AI 接口密钥 |
| `DEEPSEEK_MODEL` | — | **是** | 模型名 |
| `DEEPSEEK_BASE_URL_2` | 空 | 否 | 备用通道地址（主通道全失败时启用） |
| `DEEPSEEK_API_KEY_2` | 空 | 否 | 备用通道密钥 |
| `DEEPSEEK_MODEL_2` | 空 | 否 | 备用通道模型 |

---

## 两个服务的配置对应关系

```
clouddiag-server: LOG_ANALYZER_UPSTREAM = http://127.0.0.1:<log-analyzer 的 PORT>
                  LOG_ANALYZER_DIR      = <log-analyzer 项目目录的绝对路径>

log-analyzer:     PORT = <上面 UPSTREAM 里的端口>
```

AI 通道密钥两个服务**可以共用同一个**（也可用各自的额度）。

## 配置要点提醒

| 项 | 提醒 |
|---|---|
| `COOKIE_SECURE` | **最常见的部署失败原因**：HTTP 环境设 `true` → 登录后掉线 |
| `PUBLIC_URL` | 必须与实际访问地址完全一致（含协议/端口），否则桥接器连接命令指向错误地址 |
| `BRIDGE_HTTP_SECRET` | 生产环境务必改为随机值，不要用示例值 |
| `.env` 文件 | **不得提交到版本库**（见[事故记录 C1](风险与事故记录/C1-环境文件误提交公开仓库.md)） |
