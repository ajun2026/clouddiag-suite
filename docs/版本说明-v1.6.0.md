## 二、修掉的 Bug

| 问题 | 根因 | 处置 |
|---|---|---|
| 建房「创建失败：Failed to fetch」 | 浏览器拦截程序化自动下载 + 网络中断无自愈 | 改为显式「下载连接文件」按钮；失败时回查 `/api/my_rooms` 自愈；错误文案人话化 |
| 输入框被自动填充成登录名 | Chrome 密码自动填充，`autocomplete=off` 无效 | readonly 守卫（点击/按键才解锁）+ 改名 + 兜底 CSS |
| 观察画面模糊 | 固定 1280 宽 + JPEG q55 | 新增画质切换，默认清晰档（1920/q80，按屏幕像素自适应） |
| 高清截图慢 | PNG 无损 3~8MB 走客户机上联 | 默认改 JPEG q92，8 秒后提示「大图回传中」 |
| 观察区一直挂「正在抓取客户机画面…」 | 每帧都发进度通知且无清除时机 | 观察模式不再显示；收到帧即清残留提示 |
| PS 版首次抓屏像卡死 | 首次要下 6MB 抓屏组件，只在命令行可见 | 桥接器上报 notice → 网页常驻提示；老客户端 6 秒兜底提示 |
| 开机自启动输出乱码/结论数字错 | 双层 PowerShell + `Format-Table` + `wevtutil /f:text`（GBK）；结论用正则数文本行 | 改单层 PowerShell + UTF-8 + `ConvertTo-Json`；结论重写，只认解析结果、去重、取不到返回 nodata |
| 官方驱动清单没有下载链接 | 缓存不存链接（CDN token 有时效），缺"实时签发"端点 | 新增 `GET /api/tools/drivers/sign` → 302 到带新 token 的官网直链 |
| 驱动表「无直链」含糊文案 | 把服务端缺陷包装成 UI 状态 | 删除；拿不到时明确提示官网未返回该驱动下载地址 |
| SN/MTM 被要求填双人工号 | 门禁设计过重 | 取消工号门禁与录屏要求，写入直接执行（快照 + 轨迹保留） |

## 三、存储与清理

1. **服务端截图残留**：`static/downloads/` 曾堆到 772 个文件 / 94MB。新增剪枝策略——观察帧每房间只留最新 3 帧，高清截图保留 7 天；重启即清理 488 个（94MB → 36MB）。
2. **客户机截图残留（真 bug）**：清理函数只匹配 `nexpert-shot-` 前缀，而观察帧叫 `nexpert-preview-`，导致帧永不删除（每天约 4.9GB）。Go 桥接器 1.4.3 与 PS 模板 1.4.4 均已修：观察帧只留 3 帧、高清截图 24 小时过期。
3. **PS 助手 exe 自动更新**：按文件大小与服务端比对，服务端换版本后老客户端自动取新。
