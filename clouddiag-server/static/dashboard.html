Windows 客户端 (.exe)
推荐
下载后双击运行，输入 8 位房间码即连接。主力方案，最省心。
⬇ 下载 clouddiag-bridge-win64.exe (4.8MB)
双击自动请求管理员权限（UAC 弹窗点「是」即可）
⚡
Windows 命令版（免安装）
管理员 PowerShell 粘贴一行命令即连接。不下载文件、不落盘，杀毒软件友好。
iex (New-Object Net.WebClient).DownloadString("{{PUBLIC_URL}}/static/bridge.ps1")复制
查看详细步骤
1打开管理员 PowerShell
在客户机上右键「开始」菜单 → 选择「Windows PowerShell (管理员)」
2粘贴命令
回车后按提示输入 8 位房间码
免交互（把 ABC12345 换成你的房间码）：$env:BRIDGE_ROOM = "ABC12345"; iex (New-Object Net.WebClient).DownloadString("{{PUBLIC_URL}}/static/bridge.ps1")
3完成配对
看到绿色 Connected 即连接成功，保持窗口开启即可远程诊断
如提示脚本被系统拦截，可改为下载后运行：powershell -ExecutionPolicy Bypass -File bridge.ps1 -Room ABC12345
🐧
Linux 客户端
Ubuntu / UOS / KOS / 麒麟 / 龙芯等发行版通用，一条命令安装。
⬇ 下载 x86_64 桥接器
curl -sL {{PUBLIC_URL}}/static/install-linux.sh | bash复制
仅支持 x86_64 架构；ARM64 / 龙芯版本制作中
查看安装说明
1方式一：一键安装（推荐）
在客户机终端粘贴上面命令回车——自动检测架构、下载对应版本、安装到 /usr/local/bin/bridge，然后按提示输入 8 位房间码启动。需要 root 权限（自动用 sudo）。
2方式二：手动安装（已下载二进制）
① 给执行权限：
chmod +x clouddiag-bridge-linux-amd64复制
② 放入系统目录（任意目录也可，这里以 /usr/local/bin 为例）：
sudo mv clouddiag-bridge-linux-amd64 /usr/local/bin/bridge复制
③ 启动（把 ABC12345 换成你的房间码）：
bridge -server {{WS_URL}} -room ABC12345复制
3完成配对
看到 Connected 即连接成功，保持终端开启即可远程诊断。重启电脑后需重新启动桥接器（一次性使用，不驻留后台）。
4用完清理（可选）
诊断结束后不再需要时，一条命令卸载桥接器（删除程序与审计日志，并恢复系统自带的 bridge 命令）：
curl -sL {{PUBLIC_URL}}/static/uninstall-linux.sh | sudo bash复制
桥接器能力：AI 远程诊断（系统信息 / 事件日志 / 驱动 / BIOS）· 远程命令 · 文件传输 · 断线自动重连
安全机制：只读诊断自动执行；修改 / 危险操作需在对话页人工审批

Windows 工具
Windows 客户机专用工具集合，通过桥接器远程推送到客户机执行
Windows 系统日志
只读
导出系统/应用程序/安全事件日志（.evtx）到客户机本地 C:\DiagLogs\日期\logs\——数据不经过云端，只显示清单
Dump / Minidump 收集
只读
收集蓝屏转储文件（Minidump + MEMORY.DMP）到客户机本地 C:\DiagLogs\日期\dump\——数据不经过云端，只显示清单
蓝屏 / Dump 分析
只读
分析蓝屏崩溃：事件日志信号 + dump 解析（停止码/参数）+ WinDbg 深度定位——支持指定路径分析拷来的 dump 并关联对应时间的 Windows 事件日志
RAID 信息（VROC / RSTe / Broadcom）
只读
抓取 RAID 控制器信息（Intel VROC / Intel RSTe / Broadcom-LSI 三件套）——自动分发工具到客户机执行
硬盘健康检测（SMART）
只读
读取硬盘 SMART 健康数据（温度/重映射坏道/通电时长/SSD 磨损）——自动分发 smartctl 工具到客户机执行
SIO Log 硬件诊断日志
只读
抓取 SIO EEPROM 硬件事件日志（温度/电压/异常记录，共 124 条）——自动下载 HWDiag 工具到客户机并执行，日志可查看/下载
ThinkStation 日志采集
采集 · 数据留本地
一键采集 ThinkStation 全套日志（软件/BIOS/systeminfo/系统日志/dump/进程/硬件/RAID/SMART/显卡/DirectX 共 20+ 项）——7z 打包到客户机本地，服务器只返回包路径与大小（数据不上云）
SN/MTM 刷写
写入类 · 需审批
ThinkStation 工作站更换主板后，将正确的序列号(SN)与机型型号(MTM)写入 BIOS DMI 区
写入后无法撤销，请仔细核对 SN / MTM 再点击刷写
OA3 密钥读取 / 激活
只读 + 写入
读取主板内置 OA3 系统激活密钥（SoftwareLicensingService），并可导入密钥激活当前系统——换主板后重装/激活用
主板 OA3 密钥:
激活系统会导入密钥并尝试在线激活，请确认密钥与当前系统版本匹配
BIOS 信息读取
只读
通过联想 WMI 接口（Lenovo_BiosSetting）读取当前机器 BIOS 全量配置——不重启、不改设置，纯采集
